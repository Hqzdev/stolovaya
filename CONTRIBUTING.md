# Участие в разработке

1. Создайте ветку от `main` с понятным названием.
2. Запустите проект по [инструкции](docs/SETUP.md).
3. Внесите изменение, соблюдая [AGENTS.md](AGENTS.md).
4. Выполните `npm run lint`, `npm run typecheck`, `npm run build`.
5. Опишите результат, причину изменения и выполненные проверки в pull request. Для интерфейса приложите скриншот.

Не отправляйте `.env`, дампы с настоящими данными или сессиями, `node_modules` и результаты сборки. Изменение модели БД сопровождайте новой SQL-миграцией. При изменении публичного ответа API обновляйте общие интерфейсы и OpenAPI-схемы.

Имена сущностей в коде — на английском, интерфейс и документация — на русском. Используйте композицию, небольшие компоненты, сервисы с одной ответственностью и параметризованные SQL-запросы.

Проверки `npm run verify` и `npm run verify:browser` изменяют локальные данные на время сценария. Запускайте их на отдельной базе; созданные ими заказы удаляются в блоке завершения.
